# AI-Enabled EMG-IMU Prosthetic Hand

An embedded prosthetic-hand prototype that combines surface electromyography (sEMG) and inertial sensing to interpret hand and wrist movements and drive servo-based actuation.

The project explores a low-cost approach to prosthetic control by combining physiological muscle-activity signals with motion information from an IMU. The system includes sensor acquisition, signal preprocessing, feature extraction, gesture classification, and embedded motor control.

---

## Overview

Myoelectric prosthetic systems use electrical activity generated by muscles to infer a user's intended movement. However, EMG signals can vary with electrode placement, muscle fatigue, and changes in limb position.

This project combines:

- **EMG** for detecting muscle activation
- **IMU** for capturing motion and orientation
- **Signal processing** for cleaning and extracting useful features
- **Machine learning** for gesture classification
- **Servo motors** for hand actuation

The goal is to create an affordable and reproducible platform for experimenting with intelligent prosthetic control.
